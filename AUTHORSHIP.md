## Author contributions (CRediT taxonomy)

Taxonomy: https://credit.niso.org/

### Ágatha L. Galhardi

- **Conceptualization** — Conceived the Brazilian replication; defined the novel dependent variable "Questionar"; operationalized the countdown timer as a conditioned reflexive motivating operation; defined telemetry scope including self-editing via keystroke layer.
- **Methodology** — Translated and culturally adapted all materials to Brazilian Portuguese; replaced confederate names with Brazilian equivalents; collected normative data (Pilot) to develop new confederate scripts; reduced trial duration to 75 s; reordered and fixed-paired blocks and confederate–script assignments; reduced TSP to increase topographic response opportunities; specified auto-typing calibrated to experimenter WPM and confederate script dropdown for stimulus control.
- **Investigation** — Conducted all 28 experimental sessions.
- **Formal analysis** — Applied Fisher's exact test; performed block-by-block and script-by-script visual inspections; calculated interobserver agreement index; wrote R scripts (readxl, ggplot2, dplyr) for figure generation.
- **Validation** — Identified and documented bugs during the Pilot; calibrated auto-typing speed; approved all software corrections and iterative refinements.
- **Data curation** — Defined telemetry structure and exported variables; co-developed Python pipeline for data processing; curated post-collection data.
- **Visualization** — Wrote RStudio scripts for automated generation of visual inspection figures.
- **Resources** — Co-provided the software as a research resource (remote server, codebase).
- **Project administration** — Coordinated software evolution throughout data collection synchronized with the experimental schedule.
- **Writing – original draft** — Wrote the dissertation, including all software descriptions, feature specifications, and evaluation.
- **Writing – review & editing** — Revised all sections of the dissertation.

### Eurico Garcia de Barros

- **Software** — Developed VBGameLab from scratch: C#/.NET 8 back-end, React front-end, SignalR real-time communication, remote server, CSV telemetry export, auto-typing module, confederate script dropdown, expanded telemetry (mouse coordinates, keystrokes, block/trial markers, response visibility).
- **Methodology (supporting)** — Implemented the dual-interface architecture, conspicuous countdown timer, auto-typing calibration, and confederate script dropdown as specified by Galhardi.
- **Validation** — Corrected and tested all bugs identified by Galhardi; implemented and tested iterative refinements throughout data collection.
- **Data curation** — Implemented automated telemetry with anonymized alphanumeric coding; structured exported fields; co-developed the Python data processing pipeline.
- **Resources** — Co-provided the software as a research resource (remote server, hosting, codebase).
- **Project administration** — Coordinated incremental software development synchronized with the experimental schedule.
- **Writing – review & editing** — Technical review of software-related sections of the dissertation.

**Not attributed:** Funding acquisition (self-funded). Supervision (dissertation advisor, outside the scope of software authorship).

## Acknowledgements

VBGameLab was developed based on the experimental procedure described by:

Oda, F. S., Lechago, S. A., Silva, B. E., & Hunt, J. C. (2022). An experimental analysis of gender-biased verbal behavior and self-editing using an online chat analog. Journal of the Experimental Analysis of Behavior, 118(1), 24–45. https://doi.org/10.1002/jeab.763

The paradigm was adapted for Brazilian Portuguese-speaking populations, with methodological modifications described in Galhardi (2026, master's dissertation, PUC-SP).

The authors thank Fernanda S. Oda for sharing the data collection protocol materials from the original study, which served as the reference for the development of the Brazilian Portuguese materials.
